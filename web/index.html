DXA2DICOM
v0.2.1

DXA 原始影像
转换为标准 DICOM

读取 Hologic 骨密度仪归档文件（.p / .r）中的 16 位原始探测器计数与成像参数，输出标准 DICOM 文件，可作为科研分析与模型训练的数据源。

Windows 版 macOS 版

离线运行，患者数据不出本机

功能

原始格式解析
读取 16 位原始计数、患者与检查信息
标准 DICOM
各数据块写成多帧 DICOM，每帧一个通道，像素值不做缩放
成像参数
设备配置、校准与分析参数原样保留（DICOM 私有标签），界面可查看、可搜索
预览
转换前预览各通道灰度图，可切换逐通道拉伸与统一窗宽
匿名化
默认不写入姓名与出生日期，患者 ID 改为哈希值
批量处理
整目录或压缩包导入，自动配对成一次检查
离线运行
不联网，患者数据不出本机

规格

已验证样本
Hologic 骨密度仪脊柱类扫描归档文件；其他设备型号与扫描部位尚未验证
输出
多帧 DICOM（Secondary Capture）；不含 BMD、T 值、Z 值等分析结果
系统要求
Windows 10 / 11（64 位）、macOS 11 及以上
本工具输出仅供科研与数据分析使用，不得用于临床诊断。
使用人体研究数据应取得伦理委员会批准，并对患者身份信息做脱敏处理。
